### Security

- `orion web` now refuses every request by default. A route is served only if
  it was registered with the new `web.HandleReadOnly`, which puts it on an
  explicit read-only allowlist and limits it to `GET` and `HEAD`; a route
  registered with `web.Handle` answers 403 until someone deliberately exempts
  it. Any state-changing request must also prove it came from this page --
  `Sec-Fetch-Site: same-origin`, or an `Origin` naming this exact host and
  port -- and a request that carries neither header is refused rather than
  waved through.
