### Added
- Tickets are now routed to the actor that matches their label, component or issue type, instead of every ticket landing on the backend developer. A `documentation` label or issue type goes to a new docs actor (sonnet); a UI label or component goes to the frontend actor; everything else still defaults to the implementer, and the run says out loud which actor it picked and why. QA's fix loop now resumes the actor that opened the branch, so a routed ticket does not end up with its fix committed under a different actor's session.
