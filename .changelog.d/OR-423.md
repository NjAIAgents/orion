### Fixed

- **A watcher whose queue is stuck behind failed tickets now says which ones.**
  A ticket labelled `orion-failed` is never retried, so once everything left
  in the queue depends on one, nothing can start. The watcher used to print
  only "blocked by" lines and, an hour later, stop with "achieved nothing".
  It now names the failed tickets it is waiting on, with how to requeue them,
  on each idle pass and in the stop message.
