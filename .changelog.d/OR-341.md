### Fixed

- **Windows: a running agent's claim could be stolen out from under it.** The liveness
  check used the POSIX `Signal(0)` probe, which Windows has no equivalent of -- so every
  live process read as dead and a watcher was free to take its ticket mid-run.
- **Windows: killing a run left everything it had started still running.** The kill
  reached only the direct child, so an agent's `go test`, dev server or container
  survived it. It also made timeouts fake, since the wait ends when the output pipes
  close and a surviving grandchild holds them open.
- **Windows: concurrent writes to one file could fail outright.** Atomic replace is not
  atomic there, and a writer that lost the race got "Access is denied" rather than
  waiting its turn.
- **Windows: `orion doctor` never recognised its own hooks.** It matched the binary
  name without the `.exe`, so a correctly configured machine was told no hooks were
  wired and offered a repair that would change nothing.
