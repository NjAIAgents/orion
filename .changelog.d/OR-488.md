### Fixed

- **The work tree Orion files in the tracker now runs in the order the task list
  states.** Four gaps, all found turning one task list into 150 tickets:
  - A phase that waits on the one before it now blocks **every** task in the phase,
    not only its first — the queue does not run a phase's tasks in order, so the
    rest used to start at once.
  - Stories are blocked too. The queue picks up stories, but ordering links landed
    only on the tasks inside them, so every story was ready the moment it was
    created.
  - "Needs Phase 2", "requires T012", "depends on" and "blocked by" are read the
    same as "after". A Dependencies section whose wording is not read is now
    reported as unread, not as "states no dependencies".
  - Tasks already ticked done are created and then closed as Done, never offered to
    an agent and never part of an ordering link. They used to arrive as open work.
