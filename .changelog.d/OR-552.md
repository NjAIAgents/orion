### Fixed

- **A green batch that GitHub will not rebase now lands.** A batch whose
  members carry merge commits (for example a conflict resolved by merging the
  base in) was refused on every pass by the rebase merge and never landed.
  Orion now lands it as a merge commit when rebase is refused.
- **`orion watch` prints collect errors.** They were dropped, so a failing
  landing showed only "in integration" with nothing saying why.
