### Fixed
- `orion watch` prints its startup banner -- project, queue label, poll interval, job limit -- before it reads a credential or makes a network call, so a freshly started watcher can no longer sit silent in a way indistinguishable from a hang.
- An unresponsive Jira now fails with a message naming the server and how long Orion waited, instead of blocking a watch tick behind an error nobody could read. A Jira client built any other way than `NewJiraFromEnv` gets the same timeout rather than falling back to an unbounded one.
- `gh pr create` and `git push` -- the last two network calls on the watch path without a timeout -- are now bounded, so a stalled credential prompt or dead connection cannot park the watcher indefinitely.
