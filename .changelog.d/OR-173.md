### Fixed
- `orion collect` now reads the branch a job actually used instead of recomputing it by convention, so a retried ticket (whose branch got a `-2` suffix to avoid colliding with a prior attempt's open pull request) is looked up correctly instead of polling a branch that no longer matches.
- A ticket in `orion-ci-wait` whose pull request cannot be found is now released from `ci-wait` and marked for a human, instead of being polled forever with the same warning on every tick.
