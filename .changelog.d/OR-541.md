### Fixed

- **QA in a ticket's worktree tests that ticket's code, not the work branch's.**
  The sandbox virtualenv has the project installed from the main checkout, and
  every worktree shares it — so in a Python project with a `src/` layout, the
  generated `scripts/test.sh` imported the main checkout's copy and QA could
  report "verified clean" on a change it never ran. The script now puts the
  tree's own `src/` first on the import path. CI was never affected.
