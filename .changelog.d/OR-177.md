### Fixed
- Lesson proposals from the CI fix loop are now keyed on the fix run's stated root cause instead of the CI check name, so two different mistakes in a repo with one job matrix no longer collapse into a single vacuous "CI sometimes fails" lesson. The root cause is normalized (file paths, branch names and ticket keys stripped) so two sightings of the same mistake in different files still count as a repeat. A run with no stated root cause now proposes nothing rather than falling back to the check name.
