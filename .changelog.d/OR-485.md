### Added

- **Creating a project repository on a free GitHub plan offers to make it public,
  so `main` and `develop` can be protected.** GitHub protects a private repository's
  branches only on a paid plan, and `orion plan` used to stop at "remote did not
  finish" with no way forward but knowing that and fixing it by hand. It now asks
  whether to make the repository public, says exactly what that exposes — every
  file and the full history, including the intent, spec, plan and constitution — and
  re-applies protection on a yes. The answer defaults to no, the question never
  appears in a non-interactive run, and it appears only for the paid-plan refusal,
  not for other protection failures that visibility would not fix.
