### Fixed

- **A working run says so again.** Removing the live region left `orion watch` silent
  between "started" and a ticket's verdict: the region had carried the per-ticket
  progress, and the same facts on the console were -- and still are -- gated behind
  `--verbose`. A run of any length was indistinguishable from a hung one without
  opening the worktree by hand. Each ticket now prints one throttled progress line
  naming its elapsed time and the last thing the agent did. Driven by the agent's own
  tool calls rather than by a timer, so a run that has genuinely stopped stays silent
  and silence still means something. `--verbose` is unchanged and prints the full
  transcript as before.
