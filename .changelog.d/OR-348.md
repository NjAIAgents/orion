### Changed

- **A pull request now runs the Linux leg only.** macOS joins Windows in running on
  pushes to `develop` and `main`, where work actually lands, rather than on every
  intermediate attempt. Measured first: macOS was 1.6-2.6x Linux and therefore the
  critical path on every pull request, and a quarter of branches are built more than
  once because each fix attempt re-triggers the suite. Nothing reaches a release without
  a verdict from all three platforms.
