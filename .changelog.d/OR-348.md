### Changed

- **A pull request runs Linux and Windows; macOS runs where work lands.** The split is by
  what breaks rather than by what is cheap: Windows produced a week of real
  platform defects and is worth waiting for on every attempt, while macOS has produced
  none and is 1.6-2.6x Linux on every one. Measured first -- over 200 runs a quarter of
  branches were built more than once, so an intermediate leg is paid per attempt, not
  per branch. Pushes to `develop` and `main` still run all three.
