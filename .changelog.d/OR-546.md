### Changed

- **The CI fix loop is on by default** (`ci.auto_fix`). A red build — including
  a ticket a batch convicts — goes back to the agent on its own branch instead
  of `orion-failed` and a full re-run from scratch. It stays bounded: three
  attempts by default (`ci.max_fix_attempts`), and it stops at once when the
  same failure repeats. A project that sets `auto_fix: false` keeps it off.
