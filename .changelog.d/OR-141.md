### Fixed
- Killing a `claude -p` run on wall-clock timeout now kills its whole process tree, not just the direct child. Previously a grandchild the agent spawned via `bash` (a test run, `npm`, a dev server, `docker`) survived the kill and kept running in the background, orphaned -- holding the worktree, burning CPU, and possibly still writing files after Orion reported the run stopped. Unix only for now; Windows keeps today's direct-child-only kill.
